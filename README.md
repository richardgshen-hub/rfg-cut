# RFG Cut

一个本地优先的中文采访与活动短视频编辑器原型。

当前交互原型覆盖：

- 原片、音频与字幕轨道时间线；
- 竖版 / 横版画幅切换；
- 播放位置拖动与播放状态；
- 可选择的 AI 高光建议；
- 文稿时间点跳转；
- 口癖和停顿处理、生成高光、导出队列的本地状态反馈。

## AI 驱动的两条路径

RFG Cut 不把浏览器网页伪装成能直接调用你的 ChatGPT 订阅。它提供两种明确的接入方式：

1. **Codex Agent 模式（已附源码）**：`plugins/rfg-cut-agent/` 是一个本地 Codex 插件。它让 Codex 负责理解 Brief、逐字稿与剪辑意图，随后调用 RFG Cut 的 MCP 工具生成可复核计划；只有你确认精确时间范围后，才允许调用本机 FFmpeg 输出初剪 MP4。网页右上角“交给 Codex”会复制包含项目上下文的提示词。
2. **独立 Web 模式（后续服务端接入）**：面向不使用 Codex 的客户，需要在服务端配置模型 API 并按 API 用量计费；绝不把 API Key 放进浏览器，也不把 ChatGPT/Codex 订阅额度当成网页 API。

Codex Agent 模式的模型推理由用户正在使用的 Codex 宿主负责；RFG Cut 的本地“生成复核计划”不调用云端模型，实剪只在明确确认后运行本机 FFmpeg。

## 真实可用的第一条链路

1. 选择浏览器能解码的视频或音频文件；素材只在本机内存中解码。
2. 点击“转写本地素材”。首次会下载多语言 Whisper Tiny 模型到浏览器缓存；后续复用本地缓存。
3. 得到带时间码的逐字稿、按逐字稿生成的高光建议，以及基于规则的口癖、停顿和候选换气口提示。
4. 下载真实转写生成的 SRT，或下载包含 Brief、逐字稿、清理规则和高光时间码的剪映交接包。

转写使用 [Transformers.js](https://github.com/huggingface/transformers.js) 的浏览器端自动语音识别能力。模型下载会访问 Hugging Face；**视频和音频文件不会上传**。

目前“换气口”是根据短静音间隔提出的候选，并非医学或声学诊断；口癖/停顿删除也必须人工确认。它还没有实际裁切并渲染新视频，剪映工程仍采用交接方式。

## 剪映交接

点击右上角“交接包”会下载 `rfg-cut-jianying-handoff.json`，其中包含：

- 可编辑的内容 Brief（目标、受众、核心表达、行动号召）；
- 带时间码的逐字稿；
- 口癖、停顿、换气口的清理规则；
- 已选高光及其起止时间；
- 在剪映中复核和落剪的清单。

这个版本采用“先审阅、后落剪”的交接方式，不会直接读写剪映草稿工程。剪映官方已提供“智能剪口播”等原生能力；直接写入工程需以其未来公开、稳定的工程接口为准。

## 交付预演

仓库内附有一段由 HyperFrames 生成的 12 秒竖屏预演：`public/demo/rfg-cut-export-preview.mp4`。它以代码驱动的占位画面串起“本机转写 → 逐字稿标记 → 人工复核 → Brief / SRT / 剪辑清单交接”的产品叙事；不含真实人物或外部素材。

启动项目后，可从右上角“交付预演”直接打开成片。其可编辑源工程位于 `rfg-cut-export-preview/`；该目录内运行 `npm run check` 可做布局、动画与对比度检查，运行 `npm run render` 可重新生成 MP4。
