# RFG Cut

一个本地优先的中文采访与活动短视频编辑器原型。

当前交互原型覆盖：

- 原片、音频与字幕轨道时间线；
- 竖版 / 横版画幅切换；
- 播放位置拖动与播放状态；
- 可选择的 AI 高光建议；
- 文稿时间点跳转；
- 口癖和停顿处理、生成高光、导出队列的本地状态反馈。

它使用演示数据和代码内置的视频占位画面；尚未接入真实视频导入、转写、实际剪辑渲染、云存储或 AI 模型服务。

## 剪映交接

点击右上角“交接包”会下载 `rfg-cut-jianying-handoff.json`，其中包含：

- 可编辑的内容 Brief（目标、受众、核心表达、行动号召）；
- 带时间码的逐字稿；
- 口癖、停顿、换气口的清理规则；
- 已选高光及其起止时间；
- 在剪映中复核和落剪的清单。

这个版本采用“先审阅、后落剪”的交接方式，不会直接读写剪映草稿工程。剪映官方已提供“智能剪口播”等原生能力；直接写入工程需以其未来公开、稳定的工程接口为准。
